DarkImagePeek

Zu dunkle Bilder auf Webseiten live aufhellen – etwa die schwarze Jacke auf einem Shop-Foto, bei der man keine Details erkennt.

Schnellstart: Bookmarklet

Ohne Installation, in jedem Browser: Das Bookmarklet ist ein Lesezeichen, das beim Anklicken ein kleines Regler-Panel auf der aktuellen Seite öffnet.

Diesen Knopf in die Lesezeichenleiste ziehen:

🍏 DarkImagePeek

Lesezeichenleiste nicht sichtbar? Strg+Umschalt+B (Mac: ⌘+Umschalt+B) blendet sie in Chrome, Edge und Firefox ein.

Ziehen geht nicht (z. B. am Handy)? Code kopieren, ein beliebiges Lesezeichen anlegen und den kopierten Code als Adresse (URL) eintragen:

Benutzen: Seite mit dunklen Bildern öffnen, Lesezeichen anklicken – rechts oben erscheint das Panel. Erneut klicken oder × schließt das Panel; die Einstellung bleibt bis zum Neuladen der Seite erhalten.

Grenzen: Bilder in eingebetteten Rahmen (iframes) erreicht das Bookmarklet nicht. Einige wenige Seiten blockieren Bookmarklets durch ihre Sicherheitsregeln – dann hilft die Erweiterung.

Browser-Erweiterung

Die Erweiterung kann dasselbe wie das Bookmarklet, wirkt zusätzlich in iframes und sitzt als Apfel-Symbol in der Symbolleiste.

  • Chrome / Edge: Veröffentlichung im Chrome Web Store ist in Vorbereitung.
  • Firefox (ab Version 142): Veröffentlichung auf addons.mozilla.org ist in Vorbereitung.
Bis dahin: manuell installieren
  1. Auf GitHub über Code → Download ZIP herunterladen und entpacken.
  2. Chrome/Edge: chrome://extensions öffnen, Entwicklermodus einschalten, Entpackte Erweiterung laden und den entpackten Ordner wählen.
  3. Firefox: about:debugging#/runtime/this-firefox öffnen, Temporäres Add-on laden und die Datei manifest.json wählen. (Temporär = nach Neustart weg.)

Im Inkognito-/Privatmodus muss die Erweiterung erst in den Erweiterungs-Einstellungen freigegeben werden.

Bedienung

Regler / KnopfWirkung
Gamma (Schatten)0.3–4. Werte über 1 hellen vor allem dunkle Bereiche auf, ohne helle Stellen auszubrennen. Meist der wichtigste Regler.
Helligkeit0–300 %. Hellt das ganze Bild gleichmäßig auf.
Kontrast0–300 %. Nach dem Aufhellen etwas mehr Kontrast macht Strukturen wieder deutlicher.
MagicBewährte Einstellung für dunkle Fotos: Gamma 2.5, Helligkeit 100 %, Kontrast 120 %.
ZurücksetzenOriginalbilder: Gamma 1, Helligkeit 100 %, Kontrast 100 %.

Die Änderungen wirken sofort auf alle Bilder und Videos der Seite, auch auf nachgeladene. Tipp: Erst Magic drücken, dann mit Gamma nachjustieren.

Häufige Fragen

Werden Daten gesammelt?
Nein. DarkImagePeek sendet nichts ins Netz, speichert nichts und braucht nur die Berechtigung, nach Klick auf den aktuellen Tab zuzugreifen.

Werden die Bilder verändert?
Nein, nur die Darstellung in deinem Browser. Neu laden stellt den Originalzustand her.

Manche Bilder ändern sich nicht.
Hintergrundbilder (per CSS gesetzt) werden bewusst nicht gefiltert, da sonst der ganze Seitenbereich mit verändert würde.

Muss ich die Werte auf jeder Seite neu einstellen?
Ja, die Einstellung gilt nur für die aktuelle Seite bis zum Neuladen.
