Texte für Chrome Web Store und addons.mozilla.org (AMO). Bei Änderungen im Store hier nachziehen.

## Allgemein

- **Name:** DarkImagePeek
- **Kurzbeschreibung** (aus `manifest.json`): Dunkle Bilder auf Webseiten live aufhellen: Gamma, Helligkeit und Kontrast.
- **Beschreibung:**
  > Dunkle Bilder auf Webseiten live aufhellen: Gamma, Helligkeit und Kontrast per Regler. Ideal für zu dunkle Produktfotos in Online-Shops. „Magic“ setzt mit einem Klick eine bewährte Einstellung. Wirkt auf Bilder und Videos, auch nachgeladene. Keine Datensammlung.
- **Homepage:** https://nitram2345.github.io/DarkImagePeek/

## Chrome Web Store – Datenschutz

- **Single purpose:** Dunkle Bilder auf der aktuell geöffneten Webseite durch Anpassen von Gamma, Helligkeit und Kontrast aufhellen.
- **activeTab:** Wird benötigt, um die Bildfilter nach Klick auf das Erweiterungssymbol auf den aktuellen Tab anzuwenden. Kein Zugriff auf andere Tabs oder im Hintergrund.
- **scripting:** Wird benötigt, um das CSS für die Bildfilter und die aktuellen Reglerwerte in die aktuelle Seite einzufügen.
- **Remote code:** Nein.
- **Datennutzung:** Keine Daten erhoben.
